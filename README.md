# Mate Topp® — Portal comercial

Este repositorio contiene la versión actual del portal responsive de Mate Topp® preparada para Netlify.

## Contenido
- `site.zip`: sitio completo listo para desplegar.
- `netlify.toml`: descomprime y publica automáticamente el sitio en Netlify.

## Pendiente para Google Sheets
Falta configurar en Netlify la variable `GOOGLE_SHEETS_WEBAPP_URL` con la URL `/exec` de la aplicación web de Google Apps Script.

El token privado no se guarda en este repositorio.
